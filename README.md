**DSTDPT HOMO–LUMO Gap Prediction Using Explainable Machine Learning**

**Project Description**
This repository provides the computational dataset and Python implementation used in the research study entitled:
Explainable Machine Learning – Based Prediction for HOMO - LUMO Gap prediction in Azo-Heterocyclic Compounds: Molecular Structure-Property Relationship and Applicability-Domain

**Repository Files**

DSTDPT.ipynb – Complete Google Colab notebook containing data processing, molecular descriptor generation, feature selection, SVR model development, model evaluation, SHAP interpretation, applicability-domain analysis, and generation of figures and tables.
DSTDPT_Manuscript_Tables.xlsx – Excel file containing the molecular dataset and extracted tabulated data used in the computational analysis.

**Execution Instructions**
Download the notebook and Excel dataset from this repository.
Open the notebook using Google Colab.
Load the supplied Excel dataset.
Install the required Python packages, if not already available.
Execute the notebook cells sequentially.
The computational workflow generates the corresponding model evaluation results, tables, and visualizations.

**Software and Reproducibility**
The computational workflow was developed using Python in Google Colab. The notebook documents the data-processing procedures, molecular descriptor calculations, feature selection, model development, evaluation, and interpretation.

All research data and computational code required for reproducing the reported analysis are provided in this repository.
